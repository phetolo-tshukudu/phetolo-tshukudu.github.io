Infrastructure Reporting

A secure Spring Boot API where residents report community infrastructure issues and workers review and track incidents through to resolution.

Focus: Resident, worker and admin roles; audited status transitions; optimistic locking to prevent conflicting updates.

Java 21Spring BootMySQLJWTFlywayDocker
Explore project ↗
Explore the engineering +

Residents submit incidents with a category, description and coordinates. Workers and admins advance reports from reported to verified, in progress and resolved. Each change records its author and timestamp; optimistic locking rejects conflicting updates. The API also provides paginated filtering and incident analytics. Docker Compose runs the API and MySQL together, with database health checks and persistent storage.
